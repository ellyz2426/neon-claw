### Design Decisions
- Campaign objectives are tracked in-game via hooks in releasePrize/endGame
- Fusion inventory is separate from collection album — collection tracks discovery, fusion tracks quantities
- Confetti particles use gravity physics for natural-looking fall
- Campaign stages specify machine + mode + difficulty + theme per stage
- Season themes map to existing arena themes for visual coherence
